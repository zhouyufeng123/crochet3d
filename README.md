# 钩织玩偶 3D 重建 🧶

给钩织玩偶拍几张照片，自动重建出可以在浏览器里旋转查看的 3D 模型。

基于 AHOLO 开放平台 Lux3D 图生 3D 服务（img-to-3d，支持 1–8 张多视图照片，第一张为主视图）。

## 快速开始

1. 安装 Python 3.10+（已安装可跳过）
2. **双击 `run.bat`** —— 首次运行会自动创建虚拟环境并装依赖
3. 浏览器打开 <http://127.0.0.1:8000>

同一 WiFi 下的手机/其他电脑用 `http://你的电脑IP:8000` 也能访问。

## 模式说明

服务启动时读 `.env`（首次没有就复制 `.env.example` 为 `.env`）：

| 配置 | 说明 |
|------|------|
| `AHOLO_MOCK=1` | **演练模式**：不调用真实接口、不消耗额度，用示例模型走完整个流程（当前默认） |
| `AHOLO_API_KEY` | 真实重建的 API key。留空则自动读系统环境变量 `AHOLO_API_KEY` / `LUX3D_API_KEY` |
| `ACCESS_PASSWORD` | 访问口令。发布给朋友时务必设置；自己用留空即可 |
| `LUX3D_VERSION` | `G1`（默认）或 `G1-Turbo`（更快） |
| `HOST` / `PORT` | 监听地址与端口，默认 `0.0.0.0:8000` |

**切到真实重建**：把 `.env` 里的 `AHOLO_MOCK=` 留空（或删掉这一行），重启 `run.bat`。
每次真实重建消耗平台额度，重建一般需要 3~10 分钟。

## 使用流程

1. 上传 1–8 张照片（正面必备；背面、顶部照片可提升效果；纯色背景最佳）
2. 照片自动预处理：抠主体、统一背景、铺正方形
3. 提交后页面实时显示进度：上传 → AI 重建 → 完成
4. 完成后内嵌查看器直接旋转/缩放，可下载 GLB
5. 「重建记录」保留所有历史，随时回看或删除

## 部署到云端（Render 免费档）

1. GitHub 建一个**私有仓库**，推送本项目：
   ```
   git remote add origin https://github.com/你的用户名/crochet3d.git
   git push -u origin main
   ```
2. [render.com](https://render.com) 用 GitHub 账号登录 → New → **Blueprint** → 选仓库（自动读取 render.yaml）
3. 页面会要求填两个环境变量：
   - `AHOLO_API_KEY`：你的平台密钥
   - `ACCESS_PASSWORD`：给朋友的访问口令（**必填**，公网裸奔会被刷额度）
4. Deploy → 拿到 `https://crochet3d-xxxx.onrender.com` 即可分享

免费档说明：15 分钟无访问会休眠，首次打开约等 1 分钟唤醒（重建过程中前端每 3 秒轮询，不会中途休眠）；重启后历史记录和模型会清空（按需重新生成）；图解库是本机功能，云端为空属正常。

## 图解库 📖

桌面「玩偶」文件夹（可用 `PATTERNS_DIR` 环境变量改路径）里的 Word 图解会自动解析：

- 提取材料（用线/钩针）、针法、部件、每圈表达式
- **自动计算每圈针数与总针数**（支持 x/v/A/w/T/F/E/B/FV/FA、重复组 `3(x,v)`、`4*(A,X)`、后置 `(x,v)*5`、圈号范围 `R3-4`、部件倍数 `手*2`）
- 网页「📖 图解库」区可搜索浏览，点开看逐圈明细
- 与重建打通：同款玩偶重建后，拿图解里任一圈的真实针数做「图解标定」，密度即被精确校准
- 目前解析覆盖 ~96% 的圈（39 份图解、800+ 圈），少数特殊写法标记为未解析不计入

## 针数估算

打开任意已完成的模型，点「🧶 针数估算 → 计算针数」：

- **原理**：沿钩织轴把模型切成 N 片（N = 长度 × 纵向行密度），每片对应一圈；截面环路做傅里叶低通（保留前 8 个谐波）去除重建毛刺后量周长，乘横向密度得每圈针数；总针数为各圈求和
- **密度**：线材预设（4股牛奶棉+2.5mm 等）、自定义"针数/cm × 行数/cm"，或**图解标定**——从图解里取一圈真实针数（如"头部最宽=30"）填入，密度自动反推，精度最高（实测可到 ±3~10%）
- **实际尺寸校准**：重建模型的绝对尺寸可能不准（如毛毛虫被放大到 72.9cm），填入实物尺寸后按比例修正
- **输出**：总针数、圈数、起针建议、最大圈、每圈针数增减表 + 柱状图、分段参考（周长曲线低谷 = 部件分界）、面积法对照值
- **⚠ 标记圈**：轮廓凸起部位（蘑菇伞檐、耳朵、相邻部件融合处），切片斜切导致针数虚高，仅供警惕
- **钩织语法正则化**：相邻圈差值自动向图解经验分布靠拢（39 份图解 444 圈统计：±6 占 44%、不加减 16%、±8 占 9%），修正重建噪声造成的离谱跳变（如 +16 → +8），标注正则化圈数
- 局限：整只玩偶按一个整体切片估算（不分头/身/四肢部件）；重建表面噪声会带来 ±15% 级别误差，结果供参考
- 从模型几何**全自动**检测针目的方案已深入研究（截面FFT/纹理自相关/表面角度采样/2D高度图FFT，合成数据 20/20 通过），但当前重建质量下真实模型不含连贯的针目周期信号——自动检测代码保留，信号不足时如实回退到密度换算，绝不输出假数据

## 导入旧模型

把之前在别处重建的 GLB 导入记录库，网页端即可回看：

```
python import_model.py --name "毛毛虫" --glb "路径/caterpillar_model.glb" --img "路径/输入图.jpg" --time "2026-08-27 20:27"
```

`--img` 可重复多次（多视图）；`--time` 省略时用文件修改时间。已导入旧项目的三个模型：Lux3D 演示模型、毛毛虫、小狗。

## 目录结构

```
crochet3d/
├── run.bat / run.py     启动入口（双击 run.bat 即可）
├── import_model.py      导入已有 GLB 到记录库
├── .env                 本机配置（不入库）
├── requirements.txt
├── app/
│   ├── config.py        配置加载
│   ├── aholo.py         AHOLO 平台客户端（上传/建任务/轮询）
│   ├── prep.py          照片预处理（抠主体、铺底、缩放）
│   ├── jobs.py          任务存储与后台流程
│   └── main.py          FastAPI 接口
├── static/              前端页面（含 model-viewer）
└── data/jobs/           每个任务一个目录：meta.json + images/ + model.glb
```

## 安全要点

- API key 只存在服务端（`.env` 或系统环境变量），永远不会下发到网页
- `ACCESS_PASSWORD` 设置后，所有接口需要口令（网页会弹窗问一次，记住在浏览器里）
- 发布方式（内网穿透 / 云服务器）等测试满意后再定
